## Why it exists

Agents need a quick way to pick up work, file an issue, or update a project card. The `task-tool`
skill shows how to do that directly with the GitHub CLI.

Install with `claude plugin install qsm-tasks@qsm-marketplace`. The skill uses `gh` with your
GitHub account and project permissions.

See the [GitHub CLI project command](https://cli.github.com/manual/gh_project_item-edit) for
updating status by project number and issue URL.
