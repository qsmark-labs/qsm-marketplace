## ADDED Requirements

### Requirement: Done work is released every two weeks

Every two weeks the Done features SHALL be picked into a release with a version and release notes
built from them, set to Released, and archived from the board two weeks later.

#### Scenario: A release is cut

- **WHEN** the two weeks end with features 3 and 7 Done
- **THEN** a release with a version exists whose notes name 3 and 7, both are Released, and both
  leave the board two weeks later
